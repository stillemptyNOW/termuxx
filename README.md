# Termuxx

Бесплатный SSH- и SFTP-клиент для iOS. Без рекламы, подписок и телеметрии.

## Возможности

- **Терминал** на SwiftTerm: xterm-256color, truecolor, панель Esc / Ctrl / Tab / стрелок над клавиатурой, выделение и копирование текста.
- **Несколько сессий одновременно**: можно переключаться между вкладками, история терминала сохраняется.
- **SFTP-менеджер**: навигация по папкам, загрузка и скачивание файлов, создание папок, переименование, удаление, встроенный редактор текстовых файлов.
- **Ключи**: генерация Ed25519, импорт OpenSSH-ключей (Ed25519 и RSA), установка ключа на сервер в одно касание.
- **Сниппеты**: частые команды отправляются в терминал одной кнопкой; можно задать команду, которая выполняется при входе.
- **Безопасность**: пароли и ключи хранятся в Keychain, ключ сервера проверяется по принципу known_hosts, есть блокировка Face ID.
- **6 тем терминала** и настройка размера шрифта.
- **Быстрое подключение** по строке `user@host:port`.

## Установка

1. Откройте [Releases](../../releases/latest) и скачайте `Termuxx.ipa`.
2. Подпишите и установите файл через eSign, Sideloadly, AltStore или TrollStore.

## Сборка

`.ipa` собирается автоматически в GitHub Actions при каждом пуше в `main`. Локальная сборка:

```bash
brew install xcodegen
xcodegen generate
open Termuxx.xcodeproj
```

Иконка генерируется скриптом `scripts/make_icon.py`.

## Ограничения

iOS приостанавливает приложения в фоне, поэтому через ~30 секунд после сворачивания SSH-сессия может оборваться. Переподключение — кнопка «Снова».
