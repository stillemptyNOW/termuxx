# Termuxx для Windows

SSH/SFTP-клиент и терминал с вкладками — бесплатная замена MobaXterm. Те же серверы, ключи и сниппеты,
что в Termuxx для iPhone и Linux: переносятся через резервную копию `.termuxx`.

## Установка

Скачайте из [Releases](../../../releases/latest):

- `Termuxx-Setup-<версия>.exe` — установщик (можно выбрать папку, ярлыки на рабочем столе и в «Пуске»);
- `Termuxx-Portable-<версия>.exe` — портативная версия, работает без установки.

Сборки не подписаны сертификатом, поэтому при первом запуске Windows SmartScreen может предупредить:
«Подробнее» → «Выполнить в любом случае».

Требования: Windows 10 (1809+) или Windows 11, x64. Эффект Mica — на Windows 11.

## Возможности

- **Вкладки** с локальными оболочками: PowerShell 7, Windows PowerShell, командная строка, все дистрибутивы WSL, Git Bash (ConPTY).
- **SSH-сессии**: пароль, ключи (OpenSSH, PEM, PuTTY `.ppk`, в том числе с паролем), агент (Pageant/OpenSSH), промежуточный сервер (jump host), SOCKS5-прокси, keep-alive, tmux, команда при входе, автопереподключение.
- **Проверка ключа сервера** как в known_hosts: новый сервер — подтверждение отпечатка, изменившийся ключ — предупреждение о подмене.
- **SFTP-панель** рядом с терминалом (как в MobaXterm): загрузка и скачивание с прогрессом, перетаскивание файлов, правка во внешнем редакторе с автоматической загрузкой обратно.
- **Мониторинг** сервера: строка CPU/RAM/диск внизу окна и подробная панель с процессами, сервисами systemd и Docker.
- **Туннели**: локальный, удалённый и динамический (SOCKS) проброс портов.
- **RDP**: серверы с протоколом RDP открываются во встроенном клиенте Windows (`mstsc`).
- **Ключи**: генерация Ed25519, импорт, установка публичного ключа на сервер.
- **Импорт** серверов из сессий PuTTY, из `~/.ssh/config` и из резервной копии Termuxx (iPhone/Linux).
- **Темы** терминала, шрифты JetBrains Mono и IBM Plex Mono, тёмный интерфейс с Mica/Acrylic.

## Где хранятся данные

- `%APPDATA%\Termuxx\termuxx.json` — серверы, ключи (без приватной части), сниппеты, отпечатки, настройки.
- `%APPDATA%\Termuxx\secrets.json` — пароли и приватные ключи, зашифрованные системой Windows (DPAPI, через Electron safeStorage). Расшифровать их можно только под вашей учётной записью Windows.

Резервная копия (настройки → «Резервная копия») шифрует пароли и ключи отдельным паролем
(PBKDF2-SHA256 + AES-256-GCM, формат описан в [`docs/BACKUP_FORMAT.md`](../docs/BACKUP_FORMAT.md)).

## Сборка из исходников

Нужны Node.js 22+ и (для пересборки node-pty) Visual Studio Build Tools с C++.

```bash
cd windows
npm ci
npm start            # сборка esbuild + запуск в режиме разработки
npm run typecheck    # проверка типов TypeScript
npm run dist         # установщик и портативная версия → windows/release/
```

Проверка запуска без интерфейса (используется в CI):

```bash
release/win-unpacked/Termuxx.exe --smoke-test
```

## Устройство

- `src/main/` — главный процесс Electron: окно (Mica, свой заголовок), хранилище, ключи, локальные оболочки (node-pty), RDP, резервные копии, импорт; `src/main/ssh/` — SSH, SFTP, мониторинг, туннели (ssh2).
- `src/preload/preload.ts` — безопасный мост `window.termuxx` (контракт — `src/shared/api.ts`).
- `src/renderer/` — интерфейс на React + xterm.js.
